# Verification Control — draft v1

Recorded rationale is a fallible public process artifact. Treat it as evidence
of what the agent explicitly stated, not proof that the statement was true or
exhaustive. More actions and more rationale are not inherently better.

- 1–3 poor: no task-relevant response, repetition, ignored contradiction, or
  little discriminating evidence.
- 4–6 limited: a relevant pivot or cross-check is attempted but remains
  incomplete or leaves a core conflict unbounded.
- 7–8 good: strategy updates in response to evidence, relatively independent
  support is used, and most material conflicts are resolved or bounded.
- 9–10 excellent: a complete auditable adaptive path tests critical hypotheses
  independently and resolves or responsibly bounds every core conflict.
